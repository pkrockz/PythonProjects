## 📁 Projects

### GuardianPass Shield

A password strength checker application with a graphical user interface that evaluates passwords based on multiple security criteria.

**Features:**
- Validates password length (minimum 8 characters)
- Checks for uppercase and lowercase letters
- Verifies inclusion of numbers and special characters
- Provides strength ratings: Weak, Good, Strong, Very Strong
- User-friendly GUI built with Tkinter

**Location:** `/GuardianPass Shield/`  
**Main File:** `Main Program.py`

[View detailed documentation →](./GuardianPass%20Shield/README.md)

### Recipe Organiser

A recipe management system using linked list data structure with full CRUD operations and GUI.

**Features:**
- Add, display, search, sort, and delete recipes
- Linked list implementation for efficient data management
- Insertion sort algorithm for recipe ordering
- Linear search for finding recipes by name or category
- Interactive GUI with Tkinter

**Location:** `/Recipe Organiser/`  
**Main File:** `V7.py`

[View detailed documentation →](./Recipe%20Organiser/README.md)

## 🔧 Prerequisites

- Python 3.6 or higher
- Tkinter (usually comes pre-installed with Python)

To check if you have Python installed:
```bash
python --version
# or
python3 --version
```

To verify Tkinter installation:
```bash
python -m tkinter
# or
python3 -m tkinter
```

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/pkrockz/PythonProjects.git
cd PythonProjects
```

2. No additional dependencies are required as all projects use Python standard library modules.
